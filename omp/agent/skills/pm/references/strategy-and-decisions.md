# PM：战略与决策

只从本页选择一个叶子。候选确认前不要读取叶子正文。

| 目标 | 官方叶子 |
|---|---|
| 端到端形成产品定位、发现与路线方向 | `product-strategy-session` |
| 从结果到机会、方案和实验构造决策树 | `opportunity-solution-tree` |
| 选择 RICE、ICE、价值/成本等优先级方法 | `prioritization-advisor` |
| 判断功能投入的收入、成本、ROI 与战略价值 | `feature-investment-advisor` |
| 计算 TAM、SAM、SOM 并写明假设 | `tam-sam-som-calculator` |
| 评估行业结构和利润池 | `porters-five-forces` |
| 形成带证据的 SWOT 及交叉策略 | `swot-analysis` |
| 比较 Ansoff 四类增长路径及风险 | `ansoff-matrix` |
| 明确目标客户、类别、价值与差异 | `positioning-workshop` |
| 快速形成 Geoffrey Moore 定位陈述 | `positioning-statement` |
| 评估定价变化、留存风险与回收期 | `finance-based-pricing-advisor` |
| 判断产品处于哪个生命周期及下一步打法 | `lifecycle-play-advisor` |
| 为高风险假设选择最小验证探针 | `pol-probe-advisor` |

官方叶子路径统一为：
